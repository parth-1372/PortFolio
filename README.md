# Portfolio v2

A modern, high-performance personal portfolio website built with React, Vite, and Tailwind CSS.
Designed to showcase full-stack development skills and machine learning projects.

## 🚀 Tech Stack

- **Framework**: React 18 + Vite
- **Styling**: Tailwind CSS
- **Animations**: Framer Motion
- **Icons**: React Icons (Simple Icons)
- **Deployment**: Vercel

## ✨ Features

- **Modern UI/UX**: Dark mode aesthetic with glassmorphism and gradient accents.
- **Responsive**: Fully responsive design for all devices.
- **Performance**: Optimized for speed and accessibility.
- **Dynamic Content**: Easy to update project and skills data.

## 🛠️ Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/parth-1372/Portfolio.git
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Start development server**
   ```bash
   npm run dev
   ```
